🚀 Quick Start — 2M Powerful

8.1MB checkpoint

Train 2M from scratch (40M tokens, ~2h CPU):

pip install -r requirements.txt

# Corpus 160M chars → 40M tokens (was 85M → 20M)
python -m llm.build_corpus --out data/corpus_40m.txt --chars 160000000
python -m llm.tokenizer --vocab 4096

# 2M model: d128 L7 H8 ff384 SwiGLU 512 ctx = 2,017,152 params
python -m llm.train_2m  # 610 eff steps 9760 micro = 40M tokens
# Batch 8*512=4096 micro low-mem, 16 accum → eff 65536

# Fine-tune for any question + in-depth
python -m llm.general_qa_data --n 50000
python -m llm.finetune_chat --data data/general_qa.jsonl
python -m llm.rag_data --n 20000
python -m llm.finetune_chat --data data/rag_qa.jsonl
python -m llm.deep_qa_data --n 10000
python -m llm.finetune_chat --data data/deep_qa.jsonl

# Continuous training forever (never stops)
python -m llm.train_continuous

# Serve
python app.py  # → http://localhost:8000
# Chat: /chat.html (2M), Playground: /llm_demo.html, Game: /game.html
