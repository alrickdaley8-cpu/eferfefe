Powerful despite tiny — how?

1M can't memorize internet like 7B+, so we maximize via architecture upgrades, data quality, and RAG retrieval (open-book exam).

🧠

SwiGLU + RMSNorm + RoPE

Better per-param capacity than GELU. 3*96*256=73k same params as 2*96*384 but more expressive. RMSNorm stable, RoPE no pos emb params.

🚀 Quick Start — 1 command

4.1MB checkpoint

Train from scratch (20M tokens, ~1h CPU):

python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# Corpus 115M chars → 20M tokens
python -m llm.build_corpus --chars 85000000
python -m llm.tokenizer --vocab 4096

# Upgraded training v2: SwiGLU + EMA + grad accum
python -m llm.train_v2  # 610 eff steps = 20M tokens
# Resume with validation
python -m llm.train_resume  # continues to 20.15M

# General QA + RAG + Deep fine-tune for any question
python -m llm.general_qa_data --n 50000
python -m llm.finetune_chat --data data/general_qa.jsonl
python -m llm.rag_data --n 20000
python -m llm.finetune_chat --data data/rag_qa.jsonl
python -m llm.deep_qa_data --n 10000
python -m llm.finetune_chat --data data/deep_qa.jsonl

# Serve ChatGPT-style UI
python app.py  # → http://localhost:8000
# Chat: /chat.html, Playground: /llm_demo.html, Game: /game.html

Architecture:

vocab 4096 × 96 = 393k
6× Block Attn QKV 27k + Out 9k + SwiGLU 73k = 110k/layer
Total 393k + 6*110k = 1,058,016 params exact

Model Card

📊 Data

Corpus 110M chars (stories 70% originally, now mixed general knowledge). Diverse extension 30M chars random words → vocab 4096 (was 1311). Tokens.pt 20M tokens sliced, 77MB int32, ratio 5.75 chars/tok. Chat data 80k instruction examples.

⚙️ Training

AdamW β 0.9 0.95 wd 0.1 no wd on norms, cosine 5e-4→5e-5 warmup 200, grad clip 1.0, EMA 0.999, val 5% every 200 steps, best tracking, JSON logging, sample generation diverse prompts.

💾 Deployment

Checkpoint 4.1MB fp32, int8 quantized ~2MB via quantize.py. Runs on CPU 100 tok/s. Context 256, RoPE extrapolates to 512. Demo server app.py serves chat.html at / with auto-reload latest checkpoint, streaming SSE, RAG fallback.
