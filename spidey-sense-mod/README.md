# 🕷️ Spidey Sense Mod (Minecraft Fabric)

A Minecraft Fabric mod inspired by **Miles Morales' spider-sense** from *Spider-Verse*.
Press a key to briefly slow time, reveal nearby hostiles through walls, and see the
signature red/orange vignette around the screen.

> ⚠️ This mod was generated by an AI agent inside the `spidey-sense-mod/` subfolder of this
> repository. The rest of the repo is unrelated (a web-based game called *Greedy Growers*) —
> you only need to copy the `spidey-sense-mod/` folder out to use it.

---

## ✨ What it does

| Effect | Detail |
|---|---|
| 🕒 **Time freeze** | World ticks freeze for 3 seconds — exactly you vs. everything else |
| 👁️ **Reveal hostiles** | All hostile mobs within 30 blocks get a red glow visible **through walls** |
| 🟥 **Vignette** | A red/orange pulse vignette fades around the edges of the screen |
| 💓 **Audio** | Heartbeat + whoosh + bass pulse on activation |
| ⏱️ **Cooldown bar** | A small red bar shows your remaining cooldown |
| 🍗 **Cost** | 1 hunger point (1/2 drumstick) per use — survival / adventure only |

---

## 🎮 Controls

- **Default keybind:** `V` (changeable in `Options → Controls → Spidey Sense`)
- **Activation:** Press once. Effect lasts 3 seconds, then 30-second cooldown.

## 🛠️ Build it

This is a standard Fabric mod project. You need:

- **JDK 17+** (e.g. Temurin / OpenJDK 17)
- **Gradle 8.x** (or just use `./gradlew` after generating the wrapper — see below)

### One-time setup — generate the Gradle wrapper

The `gradle-wrapper.jar` binary is not committed (Git can't diff binaries).
From inside the `spidey-sense-mod/` folder, run once:

```bash
gradle wrapper
```

That creates `gradlew`, `gradlew.bat`, and `gradle/wrapper/gradle-wrapper.jar`.

### Build the mod

```bash
./gradlew build
```

The compiled jar lands in `build/libs/spidey-sense-mod-1.0.0.jar`.

---

## 📦 Install it

1. Install [Fabric Loader](https://fabricmc.net/use/) for **Minecraft 1.20.1**
2. Install [Fabric API](https://modrinth.com/mod/fabric-api) (any version compatible with 1.20.1)
3. Drop `spidey-sense-mod-1.0.0.jar` into your `.minecraft/mods/` folder
4. Launch Minecraft

## 🔧 Tuning the constants

Open `SpideySenseHandler.java` and adjust the constants at the top of the class:

```java
public static final int DURATION_TICKS = 60;        // 3 seconds
public static final int COOLDOWN_TICKS = 20 * 30;   // 30 seconds
public static final int DETECT_RADIUS = 30;         // blocks
public static final int HUNGER_COST = 1;            // 1/2 drumstick
```

Rebuild with `./gradlew build` after editing.
