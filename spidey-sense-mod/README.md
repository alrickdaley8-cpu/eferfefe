# 🕷️ Spidey Sense Mod (Minecraft Fabric)

A Minecraft Fabric mod inspired by **Miles Morales' spider-sense** from *Spider-Verse*.
Press a key to drop into a comic-book freeze frame: time stops, hostiles glow through
walls, **giant "POW! / WHAM! / BAM! / THWIP!"** words explode across your screen, and
a red/orange vignette pulses at the edges.

> ⚠️ This mod was generated by an AI agent inside the `spidey-sense-mod/` subfolder of
> this repository. The rest of the repo is unrelated (a web game called *Greedy Growers*) —
> you only need the `spidey-sense-mod/` folder.

---

## ✨ What happens when you press V

| Layer | What you see |
|---|---|
| 💥 **Activation flash** | Brief white flash on the first frame |
| 🔍 **Zoom pulse** | HUD punches in by ~6%, then snaps back |
| 📳 **Screen shake** | Subtle shake that fades as the effect wears on |
| 🟥 **Danger tint** | Subtle red/orange wash over the whole screen |
| 🎯 **Glowing hostiles** | Every hostile within 30 blocks gets a red silhouette through walls |
| ⏱️ **Time freeze** | World ticks stop — only you can move for 3 seconds |
| ☄️ **Comic burst ring** | Expanding yellow/gold ring shoots out from screen centre |
| ⚡ **Speed lines** | 32 radial yellow lines rotate slowly across the view |
| 🟧 **Vignette** | Three-layered red→orange→yellow halo at the edges |
| 💬 **Comic pop-ups** | Random "POW!" "WHAM!" "BAM!" "ZAP!" "THWIP!" words fly around the screen |
| 🏷️ **Title splash** | A giant "SPIDER-SENSE!" / "DANGER!" / "WEB OF AWARENESS!" pops in centre-screen |
| 🔥 **Hostile particles** | Red flames around every detected mob |
| 🕸️ **Web burst** | A burst of white sparks around the player on activation |
| 🏁 **Finisher pop** | A big "DODGED!" pops when the effect ends |
| 🔊 **Sound** | Heartbeat + dragon growl + beacon whoosh |
| 🍗 **Cost** | 1 hunger point (½ drumstick) per use in survival |

> **No HUD bar / no cooldown indicator.** The comic pop-ups ARE the UI — the
> ability is silent on cooldown (just press again when ready).

## 🎮 Controls

- **Default keybind:** `V` — changeable in `Options → Controls → Spidey Sense`
- **Duration:** 3 seconds
- **Cooldown:** 30 seconds

## 🛠️ Build it

You need **JDK 17+** and **Gradle 8.x** installed.

### One-time setup — generate the Gradle wrapper

```bash
cd spidey-sense-mod
gradle wrapper        # creates gradlew, gradlew.bat, gradle-wrapper.jar
```

### Build the mod

```bash
./gradlew build
```

The jar lands in `build/libs/spidey-sense-mod-1.0.0.jar`.

---

## 📦 Install it

1. Install [Fabric Loader](https://fabricmc.net/use/) for **Minecraft 1.20.1**
2. Install [Fabric API](https://modrinth.com/mod/fabric-api) for 1.20.1
3. Drop `spidey-sense-mod-1.0.0.jar` into your `.minecraft/mods/` folder
4. Launch Minecraft and press **V**

## 🔧 Tuning

Open `SpideySenseHandler.java` and adjust the constants at the top of the class:

```java
public static final int DURATION_TICKS = 60;        // 3 seconds of freeze
public static final int COOLDOWN_TICKS = 20 * 30;   // 30 seconds cooldown
public static final int DETECT_RADIUS = 30;         // blocks
public static final int HUNGER_COST = 1;            // 1/2 drumstick
public static final int FLASH_TICKS = 6;            // white flash length
public static final int ZOOM_TICKS = 12;            // zoom pulse length
public static final int BURST_TICKS = 18;           // comic ring length
public static final int RANDOM_POP_INTERVAL = 8;    // ticks between POW! pop-ups
```

To change the comic vocabulary, edit `SpideySenseComicText.java`:

```java
private static final String[] ACTION_WORDS = {
    "POW!", "WHAM!", "BAM!", "ZAP!", ...
};
private static final String[] TITLE_WORDS = {
    "SPIDER-SENSE!", "DANGER!", "WEB OF AWARENESS!"
};
```

Rebuild with `./gradlew build` after editing.
